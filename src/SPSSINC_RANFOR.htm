Ranfor Estimation

This procedure estimates regression or classification random forests

►To run this procedure, from the menus choose:

 Analyze
  Ranfor Estimation...

►To estimate a forest, enter dependent (optional) and predictor variables.

If the dependent variable is categorical (nominal or ordinal), a forest of classification trees is produced; otherwise regression trees result. Any categorical predictors are automatically converted to factors in both cases. In old versions of R, a categorical variable may have no more than 32 categories. The dependent variable is omitted if unsupervised mode is used.

• Missing values require special attention. See the information below if your data have any user- or system-missing values.

Case weights and split files are not supported by this procedure.

Unsupervised mode Check this box to use unsupervised mode to analyze proximities among the cases. A number of statistical measures and plots are unavailable in this mode, and no dependent variable would be specified.

•  The proximities matrix grows rapidly in size as the number of cases increases, and it may not be practical to use this on datasets with a very large number of variables.

Options

The Options dialog specifies missing value treatment and parameters to control the estimation.

Missing Values. There are three choices for handling missing values.

• Rough, which works for all variables, imputes missing values in scale variables as the variable's median value. For categorical variables, the modal value is used with ties broken at random.

• RF impute, which is only available for predictors, imputes missing values based on a random forest.

From the underlying package documentation...
The algorithm starts by imputing NAs using the rough method. Then the forest is estimated with the completed data. The proximity matrix from the forest is used to update the imputation of the NAs. For continuous predictors, the imputed value is the weighted average of the non-missing obervations, where the weights are the proximities. For categorical predictors, the imputed value is the category with the largest average proximity. This process is iterated several times.

If you choose this option, any missing values in the dependent variable will cause the procedure to fail. You can use a filter to exclude such cases. Note: this option requires computing a matrix whose size is of order the square of the number of cases, so it is not recommended for large datasets

• Fail causes the procedure to stop if missing values are found.

Number of Trees. specifies how many trees should be constructed. The default value is 500. Some of the output plots are helpful in determining how many trees to use.

Variables Sampled at Each Node. determines how many variables, chosen at random, are considered each time a node is split. The default values depend on whether the trees are classification or regression trees. For classification trees, the default is the square root of the number of predictors. For regression trees, it is one third of the number of predictors.

Minimum Leaf Node Size.Enter the minimum size for leaf nodes in the tree. The default value is 1 for classification trees and 5 for regression.

R Random Number Seed. Enter a number to set the seed for the R random number generator in order to be able to reproduce the output if the procedure is rerun. This does not affect the SPSS Statistics random number generators - only the R generator.

Class Priors for Classification Trees. Enter a list of weights, one per category of the dependent variable. Values should be in ascending order of the categories. The weights need not sum to 1. This choice only applies to categorical dependent variables and is ignored otherwise.

Save

The Save dialog specifies the files and dataset to be created by the procedure. Using a case id variable is important if you plan to merge the results with the input dataset.

• The dataset names must not already be in use.

Name for New Predicted Values Dataset. Specify a dataset name in order to create a dataset containing the predicted values for the cases passed to the R package.

Name for New Imputed Dataset. Specify a dataset name in order to create a dataset containing the cases with missing values imputed. If no imputation was done, the values are the same as those passed in. Missing value definitions and value labels are not copied but can be applied with Apply Dictionary.

Name for New Outliers Dataset. Specify a dataset name in order to create a dataset containing an outlier measure for each case. The outlying measure of a case is computed as n / sum(squared proximity) where n is the number of cases, normalized by subtracting the median and divided by the MAD within each class.It is only available for classification trees. Note that this requires computation of a matrix of order n**2, so use it with caution

Save Estimated Forest As R Workspace. Specify a file in order to save the random forest data structure for future use, including for making predictions with new data.

Save estimated forest in memory. Check this box to keep the random forest data structure in memory for use in prediction with new data in the current session. Use Ranfor Predict on the Analyze menu to make predictions with the most recently estimated tree.

Output

The Output dialog specifies optional tables and charts to be displayed.

Variable Usage Tree. Check this box to produce a table showing how many times each predictor was actually used in splitting nodes across all the trees in the forest.

Variable Importance. Check this box to produce a plot of the predictor variables importance.

Partial Plots for All Variables. Check this box to produce partial plots for all predictors. Each partial plot shows the marginal effect of the variable on the dependent variable or the class probability as a function of the number of trees in the forest.

Multi-Dimensional Scaling Plot Check this box to produce a plot of the case proximities. You can specify the number of dimensions for the plot.

•  This plot is only available if a categorical dependent variable was specified

•  This requires a lot of memory if the dataset is large.

Additional Features

Run the command

SPSSINC RANFOR /HELP.

or press F1 with the cursor on an instance of the command to display the entire syntax description. In syntax you can specify a specific list of predictors for which partial plots should be produced.

Requirements

This command requires the the R randomForest package, which is normally installed with the command.
